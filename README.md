# Семейный бюджет

Локальный браузерный калькулятор семейного бюджета. Приложение ведёт счета, доходы и расходы, переводы, вклады, кредиты и платежи по финансовым целям. Данные хранятся в `localStorage`; предусмотрены импорт и экспорт резервной копии в JSON.

## Выполненные изменения

Ниже перечислены изменения в том порядке, в котором они вносились.

### 1. Первичный аудит

- Проверена структура HTML, CSS и JavaScript.
- Проверены расчёты вкладов, кредитов и балансов счетов.
- Выполнена проверка синтаксиса JavaScript.
- Запущен исходный набор из 15 тестов.
- Обнаружена потеря `schemaVersion` после загрузки состояния.

### 2. Исправление версии состояния

В `loadState()` восстановлено поле:

```js
schemaVersion: 2
```

До исправления состояние после загрузки сохранялось без версии. При следующем запуске оно ошибочно воспринималось как старый формат, поэтому денежные суммы могли повторно умножаться на 100.

### 3. Ограничение начисления процентов сроком вклада

- Расчёт процентов ограничен датой окончания вклада.
- Пополнения после окончания срока больше не участвуют в прогнозе.
- Добавлены тесты годовой ставки и прекращения начисления после закрытия.

### 4. Добавление даты актуальности остатка

В форму вклада добавлено поле **«Сумма актуальна на»**.

Это устранило повторное начисление процентов на текущий банковский остаток за уже прошедшие годы. Теперь:

- дата открытия описывает срок договора;
- начальный остаток начинает приносить проценты с даты его актуальности;
- последующие пополнения учитываются со своих дат;
- пополнения, уже включённые в зафиксированный остаток, повторно не прибавляются.

Для существующих вкладов дату актуальности остатка необходимо проверить при редактировании.

### 5. Уточнение показателей сводки

- Карточка «Денежный поток» сначала была переименована в «Доходы минус расходы».
- Затем она была заменена карточкой **«Основной счёт»**.
- Карточка основного счёта теперь показывает реальный доступный остаток с учётом начального баланса, операций, переводов и платежей по целям.

### 6. Выделение общих констант и утилит

Созданы:

- `constants.js` — ключи хранилища, версия схемы, ID основного счёта и типы целей;
- `money.js` — перевод рублей в копейки, обратное преобразование и нормализация чисел;
- `dates.js` — текущая дата, разбор дат, прибавление месяцев и расчёт срока;
- `formatting.js` — форматирование денег, процентов и дат.

Удалено дублирование этих функций из `app.js`, `calculations.js` и `storage.js`.

### 7. Выделение управления состоянием

Создан `state.js` с функциями:

```js
createDefaultAccount();
createInitialState();
replaceState(nextState);
resetState();
```

Прямое создание и полная замена глобального состояния удалены из `storage.js` и `app.js`.

## Расчёт вкладов

Денежные значения хранятся в копейках. Ставка в форме указывается как годовая.

- **Без капитализации:** проценты начисляются на основной остаток по фактическому количеству дней.
- **Ежемесячная капитализация:** начисленные проценты ежемесячно прибавляются к остатку и далее также приносят доход.

Например, вклад 500 000 ₽ под 13,5% на один год:

- без капитализации: прибыль 67 500 ₽;
- с ежемесячной капитализацией: прибыль будет выше — около 71 800 ₽.

Поэтому режим капитализации должен соответствовать условиям банковского договора.

## Запуск

Приложение не требует сборки. Откройте `index.html` в браузере.

## Тестирование

Из корня проекта:

```powershell
npm test
```

Либо напрямую через Node.js:

```powershell
node --test tests/*.test.js
```

Проверка синтаксиса отдельного файла:

```powershell
node --check app.js
```

На момент создания README выполняется 21 автоматический тест. Они покрывают:

- простые и капитализируемые вклады;
- високосные годы и даты пополнений;
- дату актуальности остатка;
- окончание срока вклада;
- кредитные графики и переплату;
- балансы счетов и переводы;
- движения денег по финансовым целям;
- диапазоны сводки;
- денежные и календарные утилиты;
- создание и замену состояния;
- миграцию резервной копии.
